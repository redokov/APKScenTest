# APKScenTest — сценарные регресс-тесты блока «Растениеводство» АПК

Набор сценарных тестов Vanessa Automation для проверки работоспособности
функционала растениеводства конфигурации **1С:ERP + модуль «Агропромышленный
комплекс» 2.5** (например, после обновления релиза) на тестовой базе.

## Концепция

1. **Обработка препроцессинга** (запуск всегда от администратора) сканирует
   введённые документы подсистемы АПК: путевые листы, сдельные наряды,
   заправочные ведомости, регистрации взвешиваний и т.д.
2. Из найденных документов извлекаются элементы заполнения сценариев:
   организация, подразделение, номенклатура, ответственные, техника,
   **пользователи-авторы** (тесты выполняются под их правами).
3. Препроцессинг заполняет сценарные тесты полученными данными и запускает
   Vanessa Automation.
4. Пароли пользователей не знаем и не храним: их хэш
   (`СохраняемоеЗначениеПароля`, платформа 8.5) сохраняется, устанавливается
   тестовый пароль, после прогона хэш восстанавливается.
5. Итог — отчёт (целевой формат — Allure).

## Целевая архитектура (коррекция цели, 28.10.2026)

**Продукт = установочный комплект на языке 1С:Предприятия.** Рабочий
прогон целиком в сеансе тестируемой базы: препроцессор (EPF, от
администратора) готовит данные → раннер (EPF, от администратора) гонит
тесты → **итоговый отчёт показывается в этой же сессии 1С**. В рабочем
процессе **нет python, COM и LLM**. Сервер, лицензии, дамп/откат —
обеспечивает инженер (инструкция в комплекте), комплект их не
исследует. Состав комплекта — только: препроцессор EPF, раннер EPF,
Vanessa Automation single EPF, сценарии `.feature`, инструкция.

> История: в фазах 3–4 цель мигрировала в python-стенд (`scripts/regress_run.py`
> + COM/rac-обвязка) — полезный dev-time инструмент валидации, но не
> продукт. Коррекция зафиксирована: `.ai/steering/product.md` →
> «Целевая архитектура», план — `.ai/sdd/PLAN.md` → Фаза 6, исполнение —
> спека `.ai/sdd/specs/005-pure-1c-kit/`.

## Состав комплекта dist/

Установочный комплект (собран T6, принят E2E T8 31.10.2026):

| Файл/каталог | Назначение |
|---|---|
| `dist/АпкПодготовкаСценарныхТестов.epf` | Препроцессор: скан документов АПК, генерация `.feature` по данным базы (патчи — из `scenario-patches.json`, без python) |
| `dist/АпкРаннер.epf` | Раннер: батчи по пользователям-авторам, подмена/восстановление хэшей паролей, сравнение с baseline, итоговый отчёт-форма в сессии 1С |
| `dist/vanessa-automation-single.epf` | Vanessa Automation single (движок прогона сценариев) |
| `dist/scenarios/` | 13 файлов: 10 `.feature` (5 типов документов + arm-«отражения» + smoke + негатив) + `baseline.json`, `baseline-real.json`, `scenario-patches.json` |
| `dist/ИНСТРУКЦИЯ.md` | Инструкция инженера: что обеспечить до запуска (сервер, лицензии, сеансы, дамп/откат) |

Рабочий прогон комплекта целиком в сеансе 1С: препроцессор → раннер → отчёт
в той же сессии, без python/COM/LLM. Python-хелперы `scripts/` — только
dev-time обвязка (restore базы, neg-пользователь, запуск VA-цепочки),
в комплект не входят.
