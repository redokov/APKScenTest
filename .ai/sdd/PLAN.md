## Vision

После обновления релиза ERP+АПК на тестовой базе одна команда (обработка
препроцессинга от администратора) даёт отчёт Allure: какие бизнес-сценарии
растениеводства (путевые листы, наряды, заправочные ведомости, взвешивания…)
работают, какие сломались, — с воспроизведением под правами реальных
пользователей базы, без знания их паролей.

## Фаза 2 — Препроцессинг (спека 001, ядро решения)

Внешняя обработка (EPF, исходники `src/`), форма + серверный модуль. Всегда
запускается от администратора. Функциональные блоки:

- **Сканер**: поиск проведённых документов АПК растениеводства за период
  (путевой лист тракториста, путевые листы автотранспорта, наряды на сдельную
  работу, заправочные ведомости, регистрация взвешиваний на току, акты
  списания семян/удобрений/ядов, ГСМ-документы, …— уточняется спекой).
- **Извлекатель фикстур**: организация, подразделение, номенклатура,
  ответственные, техника (транспортные средства/модели), поля/культуры,
  пользователи-авторы документов (для запуска под их правами).
- **Генератор данных прогона**: JSON-фикстуры + список (пользователь × сценарий).
- **Менеджер паролей**: save hash → set test password → (прогон) → restore
  hash; гарантированное восстановление; учёт пользователей без пароля.
- **Раннер Vanessa**: формирование VAParams, запуск TestManager
  (1cv8c /Execute vanessa-automation-single.epf /C StartFeaturePlayer…),
  мульти-прогоны по пользователям, таймауты, kill-tree.
- **Репортёр**: сбор логов VA + allure-результатов, сводка прогона
  (сценарий × пользователь × статус), итоговый отчёт.

Гейты: bsl-ls + v8std, compile-gate EPF, смоук-прогон одной фичи.

## Фаза 3 — Сценарии растениеводства (спека 002)

.feature-наборы по группам документов (приоритет):
1. Путевые листы (тракториста, автотранспорт) — открытие, заполнение,
   проведение, движения ГСМ/работ.
2. Сдельные наряды (+КТУ) — проведение, начисления.
3. Заправочные ведомости + ГСМ-цепочка (передача, перемещение, акт
   излишка/недостачи, списание по нормативу).
4. Регистрация взвешиваний на току (+ акт сортировки и сушки).
Сценарии параметризуются фикстурами; позитивные под полными правами и под
правами авторов; негативные (нет прав → ожидаемая ошибка) — по мере надобности.
