## Суть

EPF `АпкПодготовкаСценарныхТестов`: скан документов АПК растениеводства →
отбор представителей по осям покрытия (coverage-map.json) → fixtures.json →
генерация feature из шаблонов → подмена/восстановление хэшей паролей →
прогоны VA (батч=пользователь, ReturnStatus-вердикт, allure) → сводка.
Ввод документов — всегда текущей датой (`{{date}}` = ТекущаяДатаСеанса).

## Ключевые решения (для наследников)

- Карта покрытия/настройки — внешние JSON (`tests/coverage-map.json`,
  `tests/preprocessor-settings.json`), не метаданные (TD-001).
- Сопоставление авторов: `Пользователи.ИдентификаторПользователяИБ` →
  `ПользователиИнформационнойБазы.НайтиПоИдентификатору()` (TD-007).
- Раннер: `WScript.Shell.Exec("cmd /c 1cv8c…")`, таймаут → `taskkill /T /F`;
  вердикт — ReturnStatus-файл (0–4) (TD-003/TD-006).
- Тестовый пароль — случайный на прогон; VAParams-файлы удаляются после
  батча (TD-005).
- **АналитикаРасходов** — выбор в окне «Объекты затрат» ТОЛЬКО UIA-двойным
  кликом (VanessaExt встроена в single-epf): флаги батчей
  `ИспользоватьКомпонентуVanessaExt=Истина`, `ИспользоватьUIAutomation=Истина`,
  **`ЭмулироватьДвиженияМышкиVanessaExt=Ложь`** (Истина = зависание).
  Значение — производное поле фикстуры `АналитикаРасходовТекущий` (объект
  затрат текущего периода; создаётся идемпотентно
  `scripts/t8_create_objekt.py` — единственное разрешённое изменение данных).
- **ТипЗатрат** — шаг «И ВТЧ из выпадающего списка я выбираю с выбором …»
  с производным `ТипЗатратСписок` (valueMaps, представления «На …»);
  TextEdit=false у колонки запрещает «точное значение»/«по строке».
- Гектаров/Часов: dropdown-шаг открывает сессию редактирования строки ТЧ,
  текстовый шаг — нет; ВидРаботы-OnChange её убивает (порядок шагов в
  шаблоне обязателен). Порядок блоков ГСМ→Заправки→ВР — любой.
