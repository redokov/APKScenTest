  (DETACHED). rac: `session list/terminate --cluster=67cdef87-...`,
  terminate по UUID (поле `session`), вывод CRLF (нормализовать до
  сплита по \n\n); наша ИБ c6a442bb-d7a9-4d8b-a274-37ea859b26c1;
  RAS-служебный сеанс не считать блокирующим.

  term_all.py → пауза 60с → term_all.py → проверка 0 → designer.
  RestoreIB вручную: ~900с (шаблоны manual_restore*.py с мониторингом
  окон). Пустой лог + rc=1 = модалка/блокировка — смотри окна.
- **Окна/UIA**: EnumWindows-callback в PS — ТОЛЬКО ArrayList
  ($out+= в делегате НЕ мутирует — уже дважды на этом падали).
