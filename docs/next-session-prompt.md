## Vision (Фаза 4 — Регресс-конвейер)

После обновления релиза ERP+АПК на тестовой базе одна команда от администратора даёт отчёт Allure: какие бизнес-сценарии растениеводства работают, а какие сломались, — с воспроизведением под правами **реальных пользователей** базы, без знания их паролей.

1. **One-command прогон** на `dev_erpapk_demo` после «обновления релиза» (репетиция: `dt`-дамп → «обновление» → прогон → отчёт).
2. **Документация:** `docs/runbook.md` (как гонять регресс после обновления).
3. **Веб-публикация** (D7): реестр баз через Apache + `ТипКлиента` оба (тонкий + веб-клиент) — Фаза 4.

## Инструменты и паттерны (проверенные)

- **COM:** `win32com.client`, `V85.COMConnector`; чтение только; запросы `ВЫБРАТЬ ДАТАВРЕМЯ(...)` (не `NewObject("Дата")`); пустые ссылки — `= ЗНАЧЕНИЕ(Справочник.X.ПустаяСсылка)`; org фильтр — точное имя (осторожно с подстроками «Филиал НИВА -1/-2»).
- **VA probe-раннеры:** `S2_PROBE_N=<n> python scripts/<runner>.py [feature]`, verdict = ReturnStatus-файл/ва_status.log, TIMEOUT 600, `va_run.log` («не выполнен»).
- **Кириллица:** только heredoc `cat > file.py << 'EOF'` — никогда `python -c` с кириллицей и never edit inline с кириллическими строками.
- **HEADLESS / GUI:** перед любыми GUI-операциями (веб-публикация Apache, web-клиент) спросить: «сессия интерактивная? (RDP/console с видимым рабочим столом)». Если headless → `1cv8.exe /Automation` (COM), `ibcmd`, xUnitFor1C.
- **Правило 2-х попыток:** та же ошибка дважды → остановить и классифицировать (auth vs namespace vs builder vs redacted vs headless vs GUI).
- **429 / сброс биллинг-окна:** cont-after-reset взведён (`arm_cont_after_reset.py --repeat 30 --ttl 60`); «продолжи» — норма, продолжай с места остановки.
- **Оркестрация:** orchestrate → subagents do the tools; sequential COM/VA; parallel only independent reads.
- **Полная цепочка АРМов** для справки: заправки → выпуск с поля → выпуск услуг → производство продукции → выработка (все отражаются); расход топлива (трактор) — включён; перемещения/ЗП процентом — без данных для наших фикстур.
