## Готовые рецепты T3/T4 (проверено двойным зелёным / зелёным прогоном)

1. **Подразделение — по КОДУ** («00-000459» СТФ Агидельская, «00-000033» СТФ №1,
   «00-000386» Мелихово МТФ, «00-000385» Грибановка МТФ): поиск матчит код,
   код уникален → 1 строка. По имени НЕЛЬЗЯ — substring-матч ловит мусорные
   узлы-подстроки («Животные на откорме СВН … СТФ Агидельская СТФ Агидельская»,
   «Бык [ремонтное] МТФ Грибановка МТФ Грибановка»).
2. **Ферма (было/получатель) — по строке именем** ПОСЛЕ корректного Подразделения
   (фильтр ChoiceParameterLinks Отбор.Владелец=Подразделение, у владельца 1 ферма).
   Ферма-СТО/ФермаСтало/ПричинаПеремещения без фильтра владельца — по КОДУ
   («ЦБ-000016» СТФ Стерлитамакская, «00-000001» причина «Перемещение между
   фермами» — дубль имени!).
3. **Номенклатура «Молоко» — по КОДУ «00-00000193»** (строка «Молоко» не уникальна:
   «Молоко "Останкинское"…»). «Мясо свинина» — по строке ок.
4. **Tumbler (RadioButtonField, ChoiceList) — НЕ dropdown**: «из выпадающего
   списка» падает. Рецепт: «я читаю данные текущего профиля клиента
   тестирования» + «я делаю клик по элементу формы '$PIDКлиентаТестирования$'
   '<Значение>' '' UI Automation». Применимо: ВидОперации ПадежЗабой («Забой»),
   ВидОперации ВнутрРасходМолока («Перемещение на другую ферму/склад» — кликать
   ДО ТЧ, иначе видРасхода/получатели недоступны), ВидОперации Перевод КРС
   («В ремонтное стадо» — кликать ДО подбора, влияет на отборы).
5. **ReadOnly-агрегаты не вводить**: УчетныйЛист СВН/КРС — все агрегаты и ТЧ RO
   (авто после УчетнаяГруппаПриИзменении), вручную только шапка +
   КормящиеСвиноматки (СВН). МассаПривеса/ВсегоМолока/Итоги — вычисляемые.
6. **Опорос: СтатусОпоросившихся** — rep «Проверяемые лактирующие» недостижим
   (ChoiceParameters отбор Категория=Основные+Кормящие; набор для СТФ Агидельская
   не содержит «Проверяемые супоросные» → авто-подбор пуст). Вводить вручную
   «Основные лактирующие» (в шаблоне — патч по номеру представителя).
7. **КРС-статусы** (АпкСтатусыКРСГрупповогоУчета, 24 шт., имена уникальны, коды
   00-01..00-19 в tmp/s006/krs-status-codes.txt): по строке полным именем работает
   В ОБЫЧНЫХ dropdown-ячейках (Поступление КРС: «Корова (осемененная)
   [основное]» — зелёный).
8. **ВнутрРасходМолока ТЧ**: Номенклатура авто (мМолоко); ВидРасхода по КОДУ
