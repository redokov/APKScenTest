## Особенности автоматизации (для будущих ночных сессий)

- Ввод в поля форм 1С 8.5: `ValuePattern.SetValue` НЕ коммитит
  значение в реквизит; обычный SendInput-набор игнорируется. Рабочая
  связка: **вставка из буфера (Ctrl+A → Ctrl+V через keybd_event
  при подтверждённом foreground) → клик по другому полю** (потеря
  фокуса = коммит).
- Кнопки форм 1С не отвечают на UIA Invoke — только реальные клики
  по координатам (mouse_event). Кнопки модалок читаются UIA (имена
  «Да»/«Нет»/«OK»), тексты модалок иногда приходят пустыми
  (задержка отрисовки) — читать повторным дампом.
- `get_value` (UIA Value) для многострочных полей возвращает только
  первую строку — вердикт/маркеры проверять скриншотом+OCR.
- Закрытие сеанса 1С: PostMessage WM_CLOSE → диалог «Завершить
  работу с приложением?» → кнопка «Завершить работу» (текст этого
  диалога, в отличие от внутриформенных модалок, снимается PrintWindow
  корректно).
- Ключи `Отключены` в `tests/test-selection.json` должны совпадать со
  значениями колонки «Шаблон» таблицы плана: для АРМ-цепочек это
  `arm-arm-*` (файл фичи `arm-NN-arm-*` → канонический шаблон с
  двойным префиксом). Мой ручной seed с ключами `arm-*` из поля
  `template` манифеста не сматчился — АРМ-группа Орлова стартовала в
  «смоуке» (потому в прогоне 2 группы, а не 1). Через форму раннера
  («Исключить выделенные») ключи формируются правильно.
