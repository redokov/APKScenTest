## Заметки по инструментам (не потерять)

- Скилл img-ocr (WinRT Await) падал в этой среде — рабочий вариант:
  inline PowerShell с AsTask/Wait (см. `tmp/regress/probe/ocr1.ps1`);
  PNG конвертировать RGBA→RGB (PIL) перед OCR; WinRT-ошибка
  транзиентна — повторить через секунду.
- COM 8.5: у ДокументМенеджера НЕТ `Метаданные()` и `ПолучитьЖурналРегистрации`
  недоступен из COMConnector — метаданные через `ПустаяСсылка().Метаданные()`;
  журнал регистрации — только выгрузкой из Предприятия.
- `ВыгрузитьЖурналРегистрации` из COM: «Несоответствие типов (параметр 1)»
  даже с 1С-датой из запроса — тупик, не тратить время.
- Кириллица: transport портит heredoc-содержимое интермиттентно (два
  случая за сессию) — write-tool надёжен; после записи проверять байты.
- rac: cluster-id обязателен (`--cluster=67cdef87-…`), ras поднят ad-hoc
  (`ras.exe cluster`), RAS-службы в Windows нет.
- Штатный отказ: «Ввод начальных остатков по ТС» не провести повторно
  (`ПоТехникеУжеВводилсяОстаток`) — пополнять баки заправочными ведомостями.
