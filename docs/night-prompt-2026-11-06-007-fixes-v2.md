## Волна 2 — Диагностика ошибок (P1, T-201)

Ровно **6 мест** (не 3, как в ревью):
`ObjectModule.bsl:1373, 1387, 3711`; раннер `Module.bsl:882, 1132, 1163`.

**Ключевое:** `ВызватьИсключение;` без параметров — это **перевыброс**, `ИнформацияОбОшибке`
и стек сохраняются. Тезис ревью «теряется причина» **ложен**. Реальный пробел — в тексте нет
**имени файла**. Поэтому добавляем контекст, а не заменяем перевыброс.

Паттерн (готовый код — `design.md §4.2`):
```bsl
	Исключение
		ИнформацияОшибки = ИнформацияОбОшибке();
		Попытка
			Чтение.Закрыть();
		Исключение
			// сбой Закрыть() не должен подменять исходную ошибку
		КонецПопытки;
		ВызватьИсключение НСтр("ru = 'Не удалось прочитать JSON-файл: '") + Путь
			+ Символы.ПС + ПодробноеПредставлениеОшибки(ИнформацияОшибки);
	КонецПопытки;
```

**ЗАПРЕЩЕНО повторять ошибку v1:** не создавать `Процедура ОбработатьОшибку(...)` с телом из
одного блока `Исключение` — это **не компилируется** (`Исключение` вне `Попытка … КонецПопытки`),
плюс `&НаСервереБезКонтекста` в объектном модуле недопустима (директив в нём 0), плюс `?:`
в BSL не существует.

**Гейт:** битый JSON → в сообщении путь + причина; `00-smoke` PASS; `bsl-ls` 0 Error → **коммит**.
