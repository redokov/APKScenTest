## T4: переписать Module.bsl раннера (главная задача сессии)

Вся серверная механика — в ObjectModule ПРЕПРОЦЕССОРА
(`src/АпкПодготовкаСценарныхТестов/Ext/ObjectModule.bsl`); раннер = тонкий
драйвер, подключает препроцессор через `ВнешниеОбработки.Подключить(Адрес,
, Ложь)` (НачатьПомещениеФайла → адрес во временном хранилище).

### Архитектура (async, чтобы Прервать работал посреди батча)

Клиентские модульные переменные (Перем в шапке): ИмяПодключенной,
ПланПрогона, ТестовыйПароль, ИндексБатча, РезультатыБатчей (Массив), Шелл,
ПроцессБатча, БатчТекущий, СнимокТекущий, ПользовательСнимка, НачалоБатча,
ПрерватьФлаг, ПрогонАктивен.

- `ПодключитьПрепроцессор`: НачатьПомещениеФайла (интерактивный выбор
  .epf) → `ПодключитьНаСервере(Адрес)` → ИмяПодключенной; заполнить
  ПутьПрепроцессора.
- `ЗапуститьПрогон`: валидация (КаталогПрогона, ИмяПодключенной) →
  ПоказатьВопрос (пароли будут подменены) → План =
  `Сервер_ПодготовитьПрогон` → ТестовыйПароль → `НачатьБатч()` →
  `ПодключитьОбработчикОжидания("ТикПрогона", 1)`.
- `НачатьБатч`: Батч = План.Батчи[Индекс]; подмена
  (ПодменятьПароль → `Сервер_ПодменитьПарольБезусловно`, иначе зондовый
  `Сервер_ПодменитьПароль`) → СнимокТекущий/ПользовательСнимка;
  `Сервер_ЗаписатьVAParams`; Шелл.Exec(КомандаЗапускаБатча) → ПроцессБатча;
  перед стартом — УбратьОсиротевшихTestClient (порт батча).
- `ТикПрогона` (каждую сек): ПрерватьФлаг → убить процесс + ЗавершитьБатч +
  стоп; Процесс.Status<>0 или таймаут Батч.ТаймаутСек → ЗавершитьБатч;
  иначе обновить СтатусПрогона («Батч N/M (user): mm:ss»).
- `ЗавершитьБатч`: восстановление пароля при ЛЮБОМ исходе
  (`Сервер_ВосстановитьПароль`, снять СнимокТекущий), чтение результата
  (`Сервер_ПрочитатьРезультат`), удаление файлов батча
  (`Сервер_УдалитьФайлыБатча`), РезультатыБатчей.Добавить; Индекс++;
  следующий батч или ФиналПрогона.
- `ФиналПрогона`: ОтключитьОбработчикОжидания; `Сервер_ЗаписатьРезультаты`;
  собрать отчёт → таблица+вердикт (см. ниже); ПрогонАктивен=Ложь.
- `ПрерватьПрогон`: ПрерватьФлаг = Истина.
- `ПриЗакрытии`: если ПрогонАктивен — убить процесс, восстановить пароль по
  СнимокТекущий (server-call в ПриЗакрытии допустим), отключить обработчик.
- `ПоказатьОтчет`: без прогона — собрать отчёт по КаталогПрогона.
- `ЗафиксироватьЭталон`: только при Вердикт PASS (проверка в обработчике).

### Контракты (не выдумывать, проверено)

- Серверные обёртки: `ВнешниеОбработки.Создать(ИмяПодключенной)` →
  методы Обработки: ПодготовитьПрогон(Каталог) → {Батчи, Предупреждения};
  СгенерироватьТестовыйПароль(); ПодменитьПарольБезусловно(Юзер,Пароль);
  ПодменитьПароль(Юзер,Пароль)→{ПарольУстановлен,...}; ЗаписатьVAParamsБатча;
  ВосстановитьПароль(Юзер,Снимок)→{ПарольВосстановлен,ЗОДВосстановлен};
  ПрочитатьРезультатБатча→{Код,Вердикт}; УдалитьФайлыБатча;
  ЗаписатьРезультатыБатчей; СобратьОтчет(Каталог) → {ПутьJSON, ПутьMD,
  ИдПрогона, Итоги{batches,scenarios,passed,failed,broken,timeout,unknown,
  negativePassed,negativeFailed}, Сценарии[{scenario,user,build,status,
  durationMs,batchStatus,returnStatus}], БатчиСводно[{user,batch,status,
  returnStatus,verdict,durationSec,pwdSubstituted,negative,passwordRestored,
  zodRestored,killConfirmed,error,scenarioCount}], ТекстMD}.
- Командная строка батча (из t6-модуля, port as-is): 1cv8c ENTERPRISE
  /TESTMANAGER /S /N /P /Out /Execute VA /C "StartFeaturePlayer;VAParams=...";
  **если Батч.Админ = Батч.Пользователь И ПодменятьПароль → ПарольМенеджера
  = ТестовыйПароль** (иначе менеджер виснет, 24.10 run10e); taskkill:
  `Формат(PID, "ЧГ=")` (NBSP-разделитель групп!); kill-tree /T /F;
  осиротевший TestClient чистится powershell Get-CimInstance по `-TPort
  <порт>` ДО старта и ПОСЛЕ любого исхода; кавычки — обёртка cmd /c.
- Baseline-сравнение (семантика python `diff_classes`, regress_run.py:422):
  BAD = failed|broken|timeout|unknown; для каждого сценария (ключ
  scenario+user): нет в базовой → NEW; равен → "="; база BAD и текущий
  passed → IMPROVED; база passed и текущий BAD → REGRESSION; иначе "=";
  ключи базовой без текущего → строки MISSING (статус пустой).
  Регрессии = REGRESSION+MISSING.
- Вердикт панели: **PASS** = прогон зелёный (failed=broken=timeout=unknown=
  negativeFailed=0) И пароли восстановлены во всех батчах
  (passwordRestored+zodRestored по БатчиСводно); иначе FAIL. Показ: статус
  счётчики + «регрессий N vs baseline <baselineOf>».
- Baseline формат (tests/baseline/baseline-real.json — образец):
  `{baselineOf, createdAt, totals{...}, scenarios[{scenario,user,status}],
  runDir}`. Запись «Зафиксировать эталон» — ЗаписьJSON (клонировать формат).
  Чтение: ПрочитатьJSON обычный (Структуры, ключи ASCII).
- Таблица: `ЗначениеВРеквизитФормы(ТЗ, "Результаты")` с колонками как в
  Form.xml; Сек = durationMs/1000 (1 знак); Негативный — флаг негативного
  батча (по user из БатчиСводно).
