## Ловушки (все кровью, из T4 — код обязан их учитывать)

1. **Кириллица**: `write` ЛОМАЕТ кириллицу в .py (U+FFFD) — py-файлы
   только bash-heredoc; BSL/XML write-ом ок, но после правки проверять
   байты: `grep -c $'\xef\xbf\xbd' <файл>` (0 = чисто). Править BSL —
   python-патчером с assert-якорями (pattern этой сессии — работает).
2. **Формы 1С**: `Новый ТаблицаЗначений` — ТОЛЬКО на сервере (клиенту
   отдаём через `ЗначениеВРеквизитФормы`); переменные модуля формы — с
   директивой `&НаКлиенте` перед группой `Перем` (паттерн VA, без
   Экспорт; «голые» Перем = «переменная не определена»); `ФайлСуществует`
   недоступен (8.5) → `Новый Файл(Путь).Существует()`; `ПоказатьВопрос` —
   процедура; обработчик ожидания — 3-й параметр Ложь; `КлючИЗначение`
   не индексируется (`Пара.Ключ`); `Соответствие` без `.Содержит`.
3. **bsl-ls ПОСЛЕ любой правки BSL** (MCP `bsl-ls_bsl_analyze`,
   severities="Error" строкой, не массивом) ДО сборки; «0 файлов» =
   проверка НЕ выполнена. Плюс `/CheckConfig` в epf-build ловит то, что
   не видит bsl-ls (тонкий клиент/сервер) — rc=0 обязателен.
4. **`Новый`/`Конец`, `ё`** — запрещённые идентификаторы; `Символы.Таб`
   (не Табуляция); `Для … Шаг -1` — парсер падает → СтрРазделить/СтрНайти.
5. **git mv + правки после** — правки не стейдятся сами: `git add -A <dir>`;
   `tmp/` и `build/*.epf` в .gitignore.
6. **Сборка EPF**: только `scripts/build_*.py` (TEMP-stub обязателен).
7. **RAS/rac**: rac без портов; кластер id см. выше; тихий фейл → сначала
   проверить RAS 1545.
8. **Прогоны**: neg-сценарий failed в allure — НОРМА (neg-passed).
   Возврат-док удалять прямым Удалить() без ОтменыПроведения (платформенный
   баг). Nohup — отдельной строкой, не в `&&`.
9. **Утро ≥08:30** — десктоп занят: UI-прогоны недостоверны, подмену
   паролей НЕ запускать. Guard-файл после FAIL снимается вручную.
10. **Стоп-правила**: одна ошибка дважды → стоп, классифицировать
    (bash-diagnose-fail), третья попытка только с новым диагнозом.
