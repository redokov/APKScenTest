`ТипАлгоритмаХешированияПароля`. Проверка на временном пользователе
`АпкСценТест_Зонд` (создан и удалён скриптом). База: localhost\dev_erpapk_demo.

## Заметки для спеки 001

- `ДатаУстановкиПароля` при восстановлении хэша НЕ откатывается (остаётся
  датой тестового пароля). Если дата критична — сохранять и возвращать также
  `ЗаписываемаяДатаУстановкиПароля`.
- Хэш — строка фиксированной длины (57 симв.), алгоритм не менялся (PBKDF2,
  `ТипАлгоритмаХешированияПароля` — enum, при COM-доступе печатается как
  COMObject; в 1С-коде препроцессора доступен напрямую).
- Пользователь без права внешнего соединения всё равно проходит аутентификацию:
  платформа различает «пароль неверен» и «внешнее соединение не разрешено» —
  это можно использовать как быструю проверку пароля без полноценного сеанса.
- Восстановление хэша = гарантированный finally-блок препроцессора
  (даже при падении прогона).
