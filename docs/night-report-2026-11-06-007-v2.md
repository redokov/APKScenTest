### Ошибки субагентов — все пойманы проверкой диффов

| Дефект от агента | Как проявлялся | Исправлено |

| `ПутьКаталога(...)` — **выдуманная** функция | bsl-ls молчит, падает только `/CheckConfig` | заменено вычислением каталога из пути файла настроек |
| вызов `Обработка.ПутиКомплектаПоУмолчанию()` **до** `Обработка = РеквизитФормыВЗначение("Объект")` | крах формы при сканировании | присваивание поднято в начало процедуры |
| проверка абсолютного пути по **последнему** символу (`Прав(Путь,1)="/"`) | `C:/...` склеивался с базой | по второму символу `:` и префиксу `//` |

| `baselinePath` через «родитель `projectDir`» | при `projectDir: "."` → пусто → `n/a` | резолв от каталога комплекта |
| `БазаПутей` вне области видимости | крах при сохранении выбора | параметр/хелпер |
| **удалены** успешные ветки `Закрыть()` и `КонецПроцедуры` (2 места раннера) | `ParseError`, утечка ресурса | восстановлено вручную |
| файлы записаны с **LF** вместо CRLF | рабочая копия «разъезжается» целиком | нормализовано в CRLF |

дешевле делать локально.

### Платформенные грабли, вскрытые `/CheckConfig` и E2E

1. **`СтартовыйКаталог()` недоступен на тонком клиенте** — падало на `/CheckConfig`
   («Проверка: Тонкий клиент»). `ПараметрЗапуска()` — тоже.
   → Якорь каталога комплекта: для раннера — каталог выбранного файла препроцессора
   (`<комплект>/dist/...`), для препроцессора — путь **файла настроек**; если определить
   нельзя — явное предупреждение и ручное поле формы.
2. **`(Новый Файл(Путь)).Метод()` не парсится** — нужна промежуточная переменная.
3. **`Файл.ЭтоКаталог` — метод, не свойство** в 8.5.4 (`ЭтоКаталог()`), хотя справочник API
   показывает и то, и другое. Ловится только **исполнением** (E2E), не bsl-ls и не compile-gate.
4. **Длинное тире `—` в комментариях = Error** `InvalidCharacterInFile`. Только ASCII-дефис.
5. **`?(a,b,c)` в BSL существует** (в отличие от C-тернарного `?:`) — не «исправлять».
6. Пустой блок `Исключение` = **Error** `MissingCodeTryCatchEx`; подавление
   `// BSLLS:MissingCodeTryCatchEx-off` ставится **перед** строкой `Исключение`, не внутри.
