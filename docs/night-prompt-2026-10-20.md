## 1. Модели — ТОЛЬКО провайдер wormsoft (models.json)

Никаких других провайдеров (freedeepseek и пр. — запрещены).

| Роль | Модель (передавать как `provider/modelId`) |
|---|---|
| Оркестратор (main-loop, ты сам) | `wormsoft/zai/glm-5.3:NVFP4` (квант, 262k ctx) |
| general-purpose субагент (правки кода/скриптов) | `wormsoft/zai/glm-5.3-flash:NVFP4` (квант, 520k ctx, text+image) |
| Explore / дешёвый поиск-зонд | `wormsoft/zai/glm-5.3-flash:NVFP4` |
| Plan (архитектура фиксов) | `wormsoft/zai/glm-5.3:NVFP4` |
| Анализ скриншотов / UIA / img-ocr | `wormsoft/zai/glm-5.3-flash:NVFP4` (image input; glm-5.3:NVFP4 — text-only, НЕ подходит) |
| bsl-linter | `wormsoft/zai/glm-5.3-flash:NVFP4` |

Правила оркестрации:
- Оркестратор НЕ пишет объёмный код сам: фикс-спеки выдаёшь субагенту
  general-purpose (glm-flash:NVFP4), сам — читаешь diff, гейтишь,
  мержишь решения.
- Поисковые вопросы («где X в ERPsrc», «как устроен Y») — Explore
  (glm-flash:NVFP4), в промте субагента давай точные команды/пути,
  проси ≤200 слов.
- До каждого Agent-вызова — локальный bash/grep первым (скил
  bash-before-subagent; ответ в 5–10 строк grep → субагент не нужен).
- Контекст оркестратора = 262k (квант-вариант меньше некванта): не
  тащи в чат длинные выгрузки/логи — всё в файлы на диск, в чат только
  дистиллят; делегирование субагентам обязательнее, чем с 1M-моделью.
- E2E-прогоны — ЭКСКЛЮЗИВНО сам, субагентов в это время не запускать
  (COM-зонды под авторами с подменёнными паролями невалидны).
- Fallback при 429/недоступности: оркестратор →
  `wormsoft/zai/glm-5.3` (неквант, 1M ctx), субагенты →
  `wormsoft/deepseek-ai/deepseek-v4-flash`. Зафиксируй переключение
  в heartbeat.
