# purpose — вики по Vanessa Automation

## Зачем

Единое место знаний по Vanessa Automation (VA) для проекта APKScenTest
(и последующих 1С-проектов с сценарными тестами): запуск через VAParams,
TestManager/TestClient, клиенты тестирования, Allure-отчёты, метки,
библиотеки шагов, диагностика падений. Вместо повторного «переоткрытия»
документации в каждой сессии.

## Ключевые вопросы

- Как формировать VAParams.json для headless-прогона (StartFeaturePlayer)?
- Как объявлять клиентов тестирования (в т.ч. под конкретным пользователем ИБ)?
- Как включить Allure-отчёт и метки, где результаты, как собрать HTML?
- Как читать вердикт прогона (лог 1С, файл статуса)?
- Известные грабли: кодировки, таймауты, kill дерева процессов, роли БСП.
