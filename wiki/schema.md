# schema — правила вики Vanessa

- Слои: `raw/` (иммутабельные выгрузки доков VA), `wiki/` (страницы агента),
  `index.md`, `log.md`, `purpose.md`.
- Frontmatter каждой wiki-страницы: id, title, url, sources.
- Имена страниц = имена файлов для `[[wikilink]]`; язык — русский;
  safe_name обрезать до 120 символов без конечных точек/пробелов.
- Каждый ответ по вики содержит ссылку на источник (URL или raw-путь).
- Ingest: raw/ → страницы wiki/ → index.md → log.md (`## [ГГГГ-ММ-ДД] операция | объект`).
- Не выдумывать: нет в вики — сказать и предложить ingest.
- lint: orphan-страницы, битые ссылки, рассинхрон index.md.
